# Singularity Slayer

A brick-breaker built around collapse, pressure, and a tightening playfield.

This repository is the public home for the project. The playable Godot source is not in this first commit. The intent of this commit is to give the game a stable place on GitHub so later source, docs, and releases have somewhere to land.

## Status

- Engine target: Godot 4
- Repository: public, early foundation
- Current commit: project presence and hygiene only
- Next commit: Godot project files when they are ready to leave the local machine

See `docs/STATUS.md` for the short working list.

## How this repo is meant to grow

1. Keep the root clean.
2. Commit source and design notes before exports.
3. Do not commit Godot cache, imports cache, or local editor state.
4. Treat each commit as a recoverable snapshot, not a finished product.
